# Milestone Execution Skill

## FORMAT CHO MỖI MILESTONE

### Header
```
## Milestone [N]: [Tên]
Status: [ ] Not Started / [/] In Progress / [x] Completed
Effort: Low / Medium / High
Dependencies: Milestone [N-1]
```

### 💡 The Why
- **Business Purpose**: Giải quyết business need gì?
- **Technical Purpose**: Về kỹ thuật đạt được gì?
- **Risks**: bảng (Risk / Likelihood / Impact / Mitigation)
- **Trade-offs**: bảng (Trade-off / Option A / Option B / Decision / Lý do)
- **Alternatives**: bảng (Alternative / Pros / Cons / Why not chosen)

### 🛠 The How
1. **Step-by-step**: Từng bước chi tiết
2. **Pseudocode**: Logic tổng quan
3. **Sample Code**: Code mẫu (có comment giải thích)
4. **Best Practices**: ✅ thực hành tốt
5. **Common Pitfalls**: ❌ lỗi cần tránh (kèm cách phòng)

### 📊 Multi-Role Review
- **BA**: Requirement? Stakeholder? KPI?
- **DA**: Data quality? Analytics readiness? Metrics?
- **DE**: Reliability? Scale x10/x100/x1000? Fault tolerance?
- **AE**: Model? Semantic layer? SSOT?
- **Dev**: SOLID/DRY? Security? Tests? Tech debt? Performance?

### 🏁 Knowledge Check
3-5 câu hỏi/bài tập kiểm tra hiểu biết. Format:
```
**Câu 1**: [Câu hỏi]
<details><summary>Đáp án</summary>[Đáp án]</details>
```

### 📝 Lessons Learned (sau khi hoàn thành)
What Worked / What Failed / Trade-offs Made / Technical Debt / Future Improvements
